# 棋盘路径节点连接表（V1.6 上线前审计，2026-10-22）

数据来源：`docs/source/棋盘v1.pptx` → `ppt/slides/slide1.xml`，用 zipfile + ElementTree 读取每个形状的 `a:off / a:ext`。
坐标统一换算到 `shared/game/board.ts` 使用的坐标系（四个起点格中心在 8.14% / 91.86%）：
`board% = 50 + (原始% − 50) × 0.91457`，原始% 以 32918401 EMU 的棋盘底板为 100%。

**来源标记**
- **〔PPTX〕** 图上直接量得到的形状和位置。
- **〔原稿〕** V1.5 规则书文字明确写了的连接或规则。
- **〔推断〕** 开发时根据图形推断的连接，原稿没有文字说明，**需要你确认**。

外圈格子编号：引擎里从 0 开始（`id`），界面上显示为"第 id+1 格"。下表两种都写。

## 3. 河道与桥

PPTX 实测：
- 两条河道横带 y 46.14%–53.86%，左边从外圈延伸到竖排，右边同样，在"终点"处与竖排相交；横带上写着"河道"。
- 外圈左边 y 43.9%–56.0% 之间没有普通格子，画着 **14 条横线组成的梯子（13 格）**，x 4.9%–7.5%；右边同样（x 92.6%–95.2%）。这一段正好在外圈 id 65（y 57.91）和 id 66（y 41.93）之间，右边在 id 28（41.87）和 id 29（57.85）之间。
- 梯子旁边写着"OR"，并画着上下双向箭头，指向河道。

| 判断 | 依据 | 来源 |
|---|---|---|
| 桥 = 外圈左右两段 13 格的梯子 | 梯子格数（13）与原稿"桥为 13 个格子"一致 | 〔PPTX〕+〔原稿〕 |
| 右边桥连接 id 28 ↔ id 29（第 29 ↔ 30 格），左边桥连接 id 65 ↔ id 66（第 66 ↔ 67 格） | 梯子正好填在这两段空档里 | 〔PPTX〕 |
| 外圈移动要跨过桥所在的空档时，先停在桥头选择"过桥 / 渡河" | 原稿："玩家在过河时……只能选择过桥 / 可选择过桥或渡河"；没写选择时机 | **〔推断〕** |
| 选择后，这一次掷骰剩余的步数作废 | 原稿没写 | **〔推断〕**（避免选完再继续走带来二次结算） |
| 过桥：付 1 金，沿梯子走 13 格，桥上每次掷骰 2 口，走完到对岸外圈格 | 原稿：过桥费 1 金币、13 格、每次掷色 2 口 | 〔原稿〕 |
| 过桥费不够：减免，不卡住 | 原稿没写 | 〔V1.6〕 |
| "OR"箭头 = 渡河：判定成功直接到对岸外圈格 | "OR"和双向箭头指向河道 | 〔PPTX〕→〔推断〕 |
| 渡河失败：留在桥头 | 原稿没写失败后去哪 | **〔推断〕** |
| 渡河判定：双骰 + 神谕；天堂河神同意 / 地狱河神反对 | 原稿给了词，算法是 V1.6 采纳的 | 〔原稿〕+〔V1.6 Q12〕 |

## 4. 连接总表（引擎实际使用）

| 从 | 条件 | 到 | 来源 |
|---|---|---|---|
| 外圈 id n | 正常前进 | id n+1（模 74） | 〔PPTX〕 |
| 外圈 id 28 | 前进要跨到 id 29 | 停在 id 28，选过桥/渡河 | 〔PPTX〕+**〔推断〕** |
| 外圈 id 65 | 前进要跨到 id 66 | 停在 id 65，选过桥/渡河 | 〔PPTX〕+**〔推断〕** |
| 桥（右）第 k 格 | 每次掷骰前进 | 第 k+点数 格；≥13 → 外圈 id 29，余数继续 | 〔原稿〕+**〔推断〕** |
| 桥（左）第 k 格 | 同上 | ≥13 → 外圈 id 66，余数继续 | 〔原稿〕+**〔推断〕** |
| 外圈 id 28 / 65 | 渡河成功 | 外圈 id 29 / 66 | **〔推断〕** |
| 外圈 id 28 / 65 | 渡河失败 | 原地 | **〔推断〕** |
| 外圈 id 10 | 神鬼道已开、恰好停在这里、选择进入 | 神鬼道节点 0，方向向下 | **〔推断〕** |
| 外圈 id 47 | 同上 | 神鬼道节点 33，方向向上 | **〔推断〕** |
| 神鬼道节点 n | 每次掷骰 | n ± 点数；恰好 16 = 抵达 | 〔原稿〕 |
| 神鬼道 | 越过节点 33（向下）/ 节点 0（向上） | 外圈 id 47 / id 10，余数沿外圈继续 | **〔推断〕** |

## 5. 界面显示

- 竖排 34 格、两条河道、两个梯子形的桥都画在棋盘上，位置按上表坐标（`shared/game/godsPath.ts`、`board.css`）。

- 桥上的玩家显示在梯子对应的格上。

## 6. 需要你确认的点

1. 入口是外圈第 11 / 48 格，并且是"停在那里才询问"，而不是"经过就可以拐进去"。
2. 上半段是天堂、下半段是地狱（按标签位置判断）。
3. 走出神鬼道另一端后回到外圈另一端的入口格。
4. 过河的时机是"外圈要跨过桥那段空档时"，并且做出选择后这次掷骰的剩余步数作废。
5. 渡河失败留在桥头（原地）。
