# V1.6 上线前人工验收（玩家可以直接照着做）

## 0. 准备

**电脑三个独立身份**（必须是三个不同的 CloudBase 匿名用户）：
1. Chrome 普通窗口
2. Chrome 无痕窗口（`Ctrl+Shift+N`）
3. Edge 普通窗口

三个窗口的本地存储互相隔离，所以是三个不同的匿名 UID。**不要**用同一个浏览器的两个普通标签页——它们共享存储，是同一个玩家。

打开地址：
- 本地：`cd /mnt/e/party-game && npm --prefix frontend run dev`，然后打开终端里显示的 `http://localhost:5173/party-game/`
- 或者预发布地址（见第 6 节，需要先确认部署）

**手机尺寸**：在 Chrome 按 `F12` → 设备工具栏（`Ctrl+Shift+M`）→ 宽度分别设 360、390、430。

**出问题时需要提供**：
- 截图（三个窗口都截）
- 房间码
- 页面底部红色报错条的完整文字（点住复制）
- `F12` → Console 里红色的报错（右键 → Copy message）
- "最近事件"抽屉里最后 5 条
