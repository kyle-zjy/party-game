# 今夜别想下桌｜V1.5 规则书（3–10 人补充修订版）

> 说明：以原 V1.5 Word 规则书为基础重新整理。原规则与新增说明、待定事项已区分；不是此前某份未保存修订稿的逐字副本。

## 阅读说明与 3–10 人适配

【修订说明】本版适用人数为 3–10 人（含 3 和 10）。游戏大厅人数低于 3 人时不能开始；达到 10 人后不能继续加入；进行中的房间不接纳新玩家，但原成员可刷新重连。

【原规则】玩家每人初始持有 5 金币、1 张三国杀战术手牌、2 张德州底牌、1 张身份牌。所有玩家遵循同一套回合流程，不按人数更改地产价格、骰子点数、租金或原有得分。

【待确认】V1.5 没有给出适用于各人数的阵营身份配置、阿瓦隆单次任务参与人数，以及个别牌义。故不能把 3–10 人的身份发放和阿瓦隆人数表写成“已定稿”。开发时需要保留房主裁定入口。

### 第一次玩，只要先记住这些

| 什么时候 | 你要做什么 | 系统应提示什么 |
| --- | --- | --- |
| 房间人数达到3–10 | 房主开局、其他人等待 | 显示所有玩家和开局条件 |
| 轮到你 | 掷一次六面骰 | 只允许当前玩家操作 |
| 移动完成 | 看落点、支付/获得金币或执行事件 | 展示格子解释和执行结果 |
| 移动落点结算后 | 翻一张小姐主牌 | 先判断德国心脏病，再执行牌义 |
| 回合尾声 | 选择使用一张战术牌或跳过 | 展示可用牌、目标和效果 |
| 交给下位玩家 | 结束回合 | 同步下家、回合与最新事件 |

【操作提示】“1口”沿用原稿惩罚单位。线下可自愿用水或替代任务处理；玩家可随时暂停或退出，不强迫饮酒。此条属于聚会组织建议，不改变原版金币与得分。

### 版本改动摘要

- 人数：明确为 3–10 人，不再使用旧版 3–15 人范围。
- 结构：保留 V1.5 原规则正文和 22 张塔罗、13 种主牌，新增新手指引与多人数据化约定。
- 未定规则：空白牌义、部分牌义只写名称、阿瓦隆组队人数、河神部分判定与旧版差异均明确标注，避免擅自编造。
- 实现策略：所有玩家看到同一状态；轮到谁、在做哪一步、结算是否完成必须明确。
## 第一部分｜V1.5 原规则（内容保留）

以下章节据所上传的 V1.5 Word 文件整理。原稿已有的数值与效果不因人数调整而更动；段落排版有所规范化。

### 0. 核心玩法

每人轮流：①掷骰 → ②移动并结算 → ③翻1张小姐牌并执行牌义 → ④可打1张手牌。全桌同时留意禁令、德州、德国心脏病、塔罗规则和阵营任务。

### 1. 开局

- 1副德州扑克牌、1副小姐+心脏病牌、1副三国杀标准手牌、1副truth or dare牌、1颗d6、角色立牌、筹码。
- 每人5金币、1张三国杀手牌、2张德州底牌、一张身份牌。
- 棋盘摆开：1张世界塔罗、德州五张公共牌（盖住）。
### 2. 回合流程

- 掷骰并移动。自然6：结算后额外掷一次，只结算落点，不额外翻小姐牌。
- 结算地图落点。
- 翻主牌：先检查心脏病数量，再执行小姐牌效果。
- 可选：打1张三国杀手牌；响应牌不限。
### 3. 地图讲解

外圈——人间：飞行棋+大富翁。

经过/停在起点：+2金币并抽1手牌。

地产：购买3金币，租金1金；和自己同色地产租金为2金，同色三处集齐后租金为3金。抵押给银行获得3金，赎回为4金。

碰撞：被撞者1口并退回起点。

中间竖排——神鬼道：第一位玩家跑完一圈后开启两端入口，若掷色结果未恰好停在终点处，则穿过终点去往另一侧。有玩家处在神鬼道时，开启河道“渡河”选项，神鬼道中最接近终点的玩家为河神。

横排——河道：玩家在过河时，若无河神，则只能选择“过桥”，需缴纳过桥费1金币，且桥为13个格子，在桥上的每一次掷色需喝2口；若存在河神，玩家可选择“过桥”或“渡河”，“渡河”时需玩家和河神依次掷色判定，后叠加结果（1-3为失败，4-6为成功；若双方相抵，则以神谕为准【可以求神拜佛】）。

中上竖排——天堂：玩家在天堂格子的每一次掷色获得一枚金币。天堂河神判定“同意行者渡河”。

中下竖排——地狱：玩家在地狱格子的每一次掷色失去一枚金币。地狱河神判定“反对行者渡河”。

### 4. 德国心脏病

数量：A/6/J=1；2/7/Q=2；3/8/K=3；4/9=4；5/10=5。（牌面上会画出来）

只看最近5张主牌；任一花色数量和恰好为5（或5的倍数），全桌立即反应。第一名+1金币，误抢罚1口。

### 5. 三国杀手牌（可随时使用）

手牌上限3。

杀 ×10：指定任意1人1口。

闪 ×8：取消杀。

桃 ×6：取消1口；救别人+1金币。

无懈可击 ×4：取消任意手牌作用。

顺手牵羊 ×4：从左/右玩家拿1金币。

过河拆桥 ×4：？

### 6. 德州扑克 / 骗子酒馆 / 梦幻拖拉机

开局时每人持有2张德州底牌。

CASINO第1次翻Flop三张，第2次Turn，第3次River并摊牌。

每阶段最多一次1金币加注。

每个德州手牌周期每人可吹牛一次：当需付1口/1金币时声明“我有X”；无人质疑则免，质疑后有X则质疑者1口，无X则原惩罚+额外1口。

地产或碰撞可提出梦幻：双方亮2张底牌，再各声明1张幻想第三牌，比三张牌型：豹子>同花顺>同花>顺子>对子>单张。

### 7. 阿瓦隆

发车任务触发：触发者为车主，挑选本车乘客上车（乘客数规定来）后匿名投票；“好人”只能投“同意”，“坏人”可投“同意”或“不同意”；出现1张FAIL即发车失败。

先到3次成功/失败即结算。胜方每人金币+1，败方每人喝1口。

### 8. 禁令 / 塔罗 / TorD

全桌唯一禁令：不能说“为什么”。

正确指出别人应当罚酒者+1金币；错误的罚1金币。

塔罗始终只有1张世界规则有效。

真心话大冒险卡二选一，不做/不答=上缴自身1/2资产+喝半杯。

### 9. 结束与计分

有玩家到达终点时，完成当前回合。

德州补齐公共牌结算；阵营按顺序继续发车后结算。

得分=抵达终点10分+每金币1分 + 每地产2分 + 每完整同色套装额外2分。最高者获胜。

## 第三部分｜22 张世界塔罗（V1.5 原稿）

## 第四部分｜3–10 人数字化补充说明

本部分为【修订说明】，用于网站实现与零基础玩家教学；不覆盖第一至三部分已经明确的原规则。

### 4.1 房间与开局

1. 有效人数 3–10；少于 3 人时房主只能等待，10 人满员后停止新玩家加入。
1. 房主点击“开始游戏”后，固定当前参与玩家顺序；所有人从同一份共享游戏状态读取棋子、金币、牌堆和回合进度。
1. 初始每人 5 金币、1 张三国杀战术手牌、2 张德州底牌、1 张身份牌；公开 1 张世界塔罗，设置德州 5 张盖住的公共牌。
1. 每回合的当前玩家、骰子结果、移动终点、已执行落点效果、已翻主牌与是否已结束回合都应记录，避免刷新导致重做。
1. 开局后玩家刷新恢复其原身份与最新房间；若有人离席，线上实现应先由房主选择等待/暂停，避免误判为退房。
### 4.2 单回合逐步引导

| 步骤 | 页面必须告诉玩家 | 下一步交互 |
| --- | --- | --- |
| ① 回合开始 | “现在轮到{昵称}。本回合先掷骰。” | 当前玩家可掷骰，其他人只观看 |
| ② 骰子 | 展示自然点数与当前塔罗是否修正移动 | 确认并逐格动画移动 |
| ③ 地图落点 | 说明名称、触发条件、金币/卡牌/位移变化 | 出现买/不买、支付、确认等具体按钮 |
| ④ 自然6 | 先正常结算，再额外掷一次；额外移动只结算落点 | 不重复主牌；额外6连锁次数待确认 |
| ⑤ 翻小姐牌 | 先在最近5张窗口检查德国心脏病，再公布本牌牌义 | 需要抢答或线下执行的让玩家确认结果 |
| ⑥ 战术选择 | 查看手牌与当前可用响应；本回合主动打牌为可选 | 打1张或跳过；目标选择需明确 |
| ⑦ 结束回合 | 显示本轮变化摘要与下一位 | 仅此时切换行动玩家 |

【推荐文案】当前玩家：“轮到你了，点骰子试试手气！”；等待玩家：“当前由 {昵称} 操作，下一步会自动同步。”；移动：“你来到了 {格名}，先完成这里的效果。”；出牌：“要用一张战术牌吗？也可以直接结束回合。”

### 4.3 同步与确认：哪些算做完一步

- 掷骰成功：必须保存自然骰值与经世界规则修正后的有效移动点数，不以动画结束作为结算依据。
- 落点结算成功：共享文档应保存新的金币、地产、位置以及本事件已处理标识。
- 主牌揭示成功：将牌写入最近5张窗口，再决定德国心脏病是否触发；同一主牌不得重复入窗口。
- 线下反应类事件：显示“等待现场结果”；记录房主或相关玩家确认，之后才能进入下一阶段。
- 战术响应：主动出牌与响应牌按原稿不同限制处理；不明优先级应暂停并请求现场裁定。
- 任何玩家中途刷新：恢复数据库记录的当前步骤和状态，不能重抽、重掷或重复发奖励。
### 4.4 3–10 人条件下的特殊小游戏

阿瓦隆：V1.5 只写了车主选乘客、好人只能交同意、坏人可交同意/不同意、出现一张 FAIL 则失败，以及三次胜负判定；但没有给出 3–10 人各人数的身份及队伍人数表。在人数配置由你确认前，系统只应显示“待房主裁定”的组队人数，不应自动生成未经确认的阵营平衡表。

德州扑克：仍按原稿每人 2 张底牌、CASINO 依次翻 Flop/Turn/River；阶段加注上限 1 金币。具体牌型结算、金币分池及和牌处理，若 V1.5 未写，应先作为待确认事项。

德国心脏病：最近 5 张主牌、同花色累计数量为 5 或其倍数的触发条件保持原样。由于 5 秒轮询不足以公平判断毫秒级抢答，本阶段可做线下主持人确认或专用实时抢答，不能用 5 秒轮询的到达顺序判第一。

### 给 Claude Code 的实现说明

- 《今夜别想下桌》游戏人数固定 3–10 人；不要再从历史 V1.0 文件读取 3–15 人作为当前限制。
- 以此文档“第一、二、三部分”的 V1.5 规则为权威；第四部分是明确标注的开发补充；第五部分是待确认事项。
- 在所有已确定事件里，完成真实共享数据库结算与交互指导；在未定事件里，呈现“规则待确认 / 房主裁定”流程，不擅自实现猜测的牌效。
- 游戏内每一步都要显示“发生了什么 → 需要谁做什么 → 结果是什么 → 下一步”四类信息。
- 先验收 3 人开局，6 人中局，10 人满房；再验收多人刷新和同一事件只结算一次。
