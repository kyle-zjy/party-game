# 《今夜别想下桌》V1.5 规则实现矩阵

规则来源：`docs/source/《今夜别想下桌》V1.5 规则书.md`（第一至三部分为原规则，第五部分为原稿自己列出的待确认事项）。未经确认，不使用 V1.0 牌义。

## 状态定义

只有达到 ④⑤⑥ 才能算"已实现"。

| 等级 | 含义 |
|---|---|
| ① 已读取 | 规则书里有这条，已经读过 |
| ② 已录入数据 | 规则文字/数值已经写进 TypeScript 数据文件 |
| ③ 已有 UI | 界面能展示这条规则 |
| ④ 已接入逻辑 | 引擎里真的改变共享游戏状态（金币、位置、手牌、喝酒提醒……） |
| ⑤ 多人同步 | 结果写入 `game_rooms`，所有玩家通过轮询看到同一结果，刷新后恢复 |
| ⑥ 已测试 | 有断言共享状态变化的单元测试，并且通过 |

表格里的 **状态** 一列：

- **已实现**：④⑤⑥ 全部达成。
- **部分实现**：效果处理器已写好并测试，但依赖的游戏模块（德州、阿瓦隆、骗子酒馆……）还没做，或者只覆盖了规则的一部分。
- **房主裁定**：规则书没写清楚，系统引导到房主现场裁定，不自动结算。
- **未实现**：只到 ①/②，或者什么都没做。

所有测试截至本次修改全部通过（`frontend/test/`）。规则来源变更见 `docs/rule-changelog.md`。

**规则来源标记**：〔原稿〕V1.5 原文明确；〔确认〕原稿有冲突或空缺、已由你正式确认；〔补充〕采纳为数字版新规则的补充方案；〔V1.6〕2026-10-22 Phase D.3–D.6 采纳的数字版补充（只对新房间生效，见 `docs/rules-v1.6-digital.md`）。

**规则版本**：`GameState.rulesVersion`。2 = V1.6（新房间），1 = V1.5（2026-10-22 之前开局的旧房间，读取时补齐）。下文"状态"一列描述 V1.6 房间。

**K 国王传承〔确认〕**：翻到 K 的人成为新国王（`ladyStatus.kingUid`）。
- 没有待执行任务（第一任）：直接给下一任留任务（`KING_WRITE`）。
- 有任务：任务转为 `IN_PROGRESS`、记录接收人 → 新国王线下执行 → 房主确认完成，或者国王/房主跳过（不扣金币、不罚酒）→ 归档到 `kingTaskHistory` → 新国王留下新任务（`PENDING`）。
- 同一玩家连续翻到 K 同样走完传承。每个动作都带 `eventId` 和步骤校验，任务只能被接收、处理、替换一次。
- 任务内容 2–80 字，拦截强制饮酒、身体接触、隐私、危险动作和侮辱的明显关键词。国王不想写时，房主可以"跳过留任务"，回合照样继续。

**和其他系统的联动**：小姐牌提醒都进入现有的非阻塞喝酒提醒，可以"以水代替 / 跳过"，可以用桃（节制下照旧禁用以水代替和桃）。事件结束后进入战术阶段，出牌规则不变。翻牌同时触发的德国心脏病照常记录。结束回合清空 `ladyEvent`，持续状态保留。

- **房主裁定流程**（正式对局里的 A–Q）：翻牌后显示花色、点数和原稿牌名 → 界面告诉全桌需要执行的人是翻牌者 → 房主宣布裁定并在线下执行 → 房主点击确认 → 进入战术阶段。

## 七、技术限制与没有做到的部分（如实记录）

1. **秘密信息不是真正保密（好友聚会信任模式）**：德州底牌、阿瓦隆身份、未揭示的投票都在所有玩家可读的 `game_rooms` 文档里，界面只给本人看。要真正保密需要：云函数持有牌堆/身份并做裁决、每位玩家一个只有本人可读的私有文档、投票写入只有云函数可读的集合。这些需要**新建云函数并调整数据库权限**，本轮按约束没有做。
2. **随机数在发起动作的浏览器生成**，不是服务端随机；数据库层保证同一动作重试时复用同一个结果，但不能防止有人改客户端代码作弊。
3. **骗子酒馆的金币惩罚**：已接入。规则书里唯一明确的"1 金币惩罚"是禁令错误指认，现在先进入待处理（不立即扣），本人支付或吹牛；正常支付（租金、买地、下注、赎回、过桥费）不能吹牛。
4. **棋盘上没有 CASINO 格子**：PPTX 和规则书都没有这个格子名，CASINO 由"德州+1 / 德扑+1"格子触发（〔V1.6〕约定）。
5. **桥格**：PPTX 在外圈左右空档里画了 13 格梯子（P0 审计时更正：之前误判为"没画桥"）。界面已按 PPTX 位置画出梯子，桥上玩家显示在对应格。
6. **神鬼道入口与河道连接点**是根据 PPTX 的几何位置推定的，原稿没有文字说明；完整连接表和"PPTX 确认 / 原稿规定 / 开发推断"的区分见 `docs/board-path-nodes.md`。
7. **真心话大冒险题库**：内置 15 道真心话 + 15 道大冒险（`shared/game/cards/truthOrDareBank.ts`），只有自愿、轻量的题；抽到的题写进共享状态，本局尽量不重复；房主或当前玩家可以换题（不受罚）。题量不大，可以直接在文件里追加。
8. **德国心脏病抢答**仍由房主录入第一反应者。
9. 没有在真实手机浏览器上验收（本机缺少浏览器运行库）；需要按 `docs/multiplayer-acceptance.md` 三浏览器验收。
